# 🧩 Userscripts

个人油猴脚本合集，提升日常网页使用体验。

## 📜 脚本列表

| 脚本 | 说明 | 安装 |
|------|------|------|
| [阿里云盘视频增强](./alipan-enhanced.js) | 替换原生播放器为 Artplayer+HLS.js，支持画质切换、播放列表、自动连播、字幕加载与切换 | [安装](https://raw.githubusercontent.com/Huang131/userscripts/main/alipan-enhanced.js) |

## 🛡️ 安全承诺

所有脚本均遵循以下原则：

- ❌ 无广告、无赞助弹窗
- ❌ 无数据上报、无第三方 SDK
- ❌ 无付费功能、无功能限制
- ✅ 所有网络请求仅发往目标网站自身 API
- ✅ 代码完全开源，可审查

## 📦 依赖声明

| 库 | 版本 | 许可证 | 使用脚本 |
|----|------|--------|---------|
| [hls.js](https://github.com/video-dev/hls.js) | 1.5.15 | Apache-2.0 | 阿里云盘视频增强 |
| [Artplayer](https://github.com/zhw2590582/ArtPlayer) | 5.2.3 | MIT | 阿里云盘视频增强 |

## 🔧 安装方式

1. 安装浏览器扩展：[ScriptCat（脚本猫）](https://scriptcat.org/) 或 [Tampermonkey](https://www.tampermonkey.net/)
2. 点击脚本列表中的"安装"链接
3. 确认安装即可
